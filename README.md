# CarePoint HMS Frontend

A premium Hospital Management System frontend built with React, TypeScript, and Tailwind CSS.

## Features

- **Premium Design**: Modern, responsive dashboard with a clean aesthetic.
- **Dark/Light Mode**: User preference persistence using `localStorage`.
- **Component-based**: Scalable architecture for hospital management modules.
- **Iconography**: Beautiful icons powered by Lucide React.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nelson-ust/carepoint_hms_frontend.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript
